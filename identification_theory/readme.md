### Описание проекта
#### Лабораторная работа 1 
В работе реализованы и исследованы два численных метода оптимизации, используемых для идентификации параметров моделей:
- **Метод прямого поиска**  
- **Симплекс-метод**

Целью лабораторной работы является определение параметров аппроксимирующей функции по экспериментальным данным с минимизацией ошибки модели.
